# Перенос листов и поворот большого превью

## Поведение

До подтверждения диапазонов оператор может выбрать лист и переместить его
на соседнюю позицию кнопками «Лист назад/вперёд». «Переместить…» переносит один
или несколько выбранных листов перед/после любой позиции текущей ленты.
Подсказка показывает исходный файл, физический номер и документ назначения.
Выбранные листы входят в диапазон целевой страницы; их взаимный порядок сохраняется.
Из опустевших диапазонов не создаются пустые регистрации. Перенос к выбранному
листу или к исключённой странице не выполняется; показана диагностическая подсказка.

Сервер сохраняет полный `page_order` ручного плана, включая исключения, с прежней
проверкой owner, TTL, revision и fence. Это явная перестановка исходных PageRef;
дубли/потери/чужие адреса запрещены. Без поля/при null остаётся первоначальный порядок.
Новый порядок доступен после готовности всех превью. Confirm копирует его в
immutable ApprovedPlan; после lock правки запрещены. Undo/reset восстанавливают
также порядок, а reload сохраняет подтверждённый сервером черновик.

PDF-комплект следует ручной последовательности. Исходник и физические номера
не меняются. JSON 1.0 сохраняет прежние поля; `documents[].pages` содержит физические
номера в порядке комплекта, поэтому может быть несортированным. Каталог page API
остаётся первоначальным; UI отдельно использует порядок показа. Это позволяет
перенести страницу через границу порций по 60 и получить именно её превью.
Автоматическое разделение и решения VLM о границах этим изменением не подменяются.

Большой viewer получил ↶/↷ по 90°, индикацию угла, корректные размеры повёрнутого
изображения и zoom/scroll без обрезки краёв. Поворот — настройка просмотра текущей
вкладки: углы по job/PageRef сохраняются при листании, SSE/polling и reload;
«Новый пакет» очищает их. В sessionStorage нет изображений/OCR. Ориентация
скачанных исходников/комплектов и вход OCR/VLM не изменяется. Поворот доступен
также после подтверждения и завершения, пока превью доступно по обычному TTL.

1. Загрузить пачку, дождаться превью, выбрать 31-й лист и перенести за 32-й.

   Комплект имеет выбранный порядок; исходник сохраняет прежний.
3. Повернуть большое превью влево/вправо, увеличить, пролистать и вернуться;
   угол этой страницы сохраняется. Проверить reload и сброс «Новый пакет».
4. После confirm перенос заблокирован, поворот просмотра остаётся доступным.
