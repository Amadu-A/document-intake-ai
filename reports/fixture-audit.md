Общие расхождения исходных JSON:

- Четыре старых файла содержат `storage://` вместо download URLs. Сравнивается
  работоспособность HTTP GET, page count, SHA-256 и byte_size; текст временного URL не сравнивается.
- UUID, batch_id, confidence и ocr_engine из иллюстративных ответов не являются эталонными фактами.
  Confidence backend не подставляет; это необязательная оценка VLM, не калиброванная точность.
- Значения `delivery_channel=paper`, `one_c.form=Бумажная`, внутренние сведения о
  способе регистрации не доказаны сканом. Без отдельного контекста ожидается null.
- Направление входящее доказуемо относительно переданной организации, но не просто
  наличием её имени в адресате. Матрица без organization_hint ожидает direction=null.
- У двух старых писем `document_kind` описательный («Гарантийное», «Сопроводительное»),
  а template_path относится к «Переписке с контрагентом». При известном направлении
  рабочая реализация использует закрытые kind/subkind каталога, описательный заголовок
  сохраняется в `requisites.title`. Исходные JSON не переписываются.
- `examples/` уже отслеживается Git. Добавление ignore не удаляет отслеживание и историю.
  Самостоятельный `git rm --cached` не выполнялся; чистый clone пока содержит эти файлы.
