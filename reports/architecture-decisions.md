# Зафиксированные решения и границы проверки

1. **Приоритет контрактов.** Изучены AGENTS.md, полное ТЗ, все renders и примеры;
   общие правила прочитаны из `shared_infrasktructure/main` на
   `839d419432fc25bc988e5871f7e53f6d282a2e77`. Локальный/remote main проекта:
   `72e001f42cb50479f5e82fb6e580f94e10ca2d98`.
   Reference `spec-extracting-ai/main`: `fa67a1467003081e502fe8f6ace5f0342e25b756`;
   изучен актуальный `scripts/up.sh`. Повторная remote-проверка подтвердила те же SHA.

2. **JSON 1.0.** Картинки содержат демонстрационную 1.1 и иной пример дерева;
   реализация сохраняет утверждённую 1.0. SHA/byte_size/TTL/provenance выдаются через
   status/manifest/headers, дополнительные служебные объекты в экспорт не добавлены.
   Старые описательные letter kinds не расширяют закрытый каталог шаблонов.

3. **Несколько источников.** VLM может связать файлы в один комплект. Регистрация
   помещается в первый source, её публичные `pages` содержат только его реальные номера.
   Полный порядок `(file_id,page_number)` находится в manifest, весь состав — в PDF.
   Предупреждение явно отмечает сквозной комплект. Нельзя интерпретировать одинаковый
   page_number разных sources как одну страницу.

4. **Сложные приложения.** `page_range` JSON 1.0 не может однозначно кодировать
   страницы разных sources или несмежную последовательность. Подробные физические ссылки
   остаются в VLM-плане/manifest, без выдуманного диапазона. Приложение с таким составом
   должно сопровождаться предупреждением; PDF содержит его реальные страницы.

5. **Bootstrap и внешние prerequisites.** Собственные secrets генерируются, но чужой
   Docling key невозможно корректно сгенерировать в проекте. Он является явным внешним
   prerequisite, наряду с Docker и работающими shared-сервисами. При отсутствии ключа
   первая команда создаёт свой sparse .env и останавливается с инструкцией. Чужие .env,
   RabbitMQ passwords и shared lifecycle не изменяются.

6. **Изоляция тестов.** SQLite применяется только в offline fixtures; production —
   PostgreSQL/Alembic. Chromium настоящий, но browser flow использует synthetic OCR/VLM
   и тестовую доставку. Эти результаты не доказывают качество shared-модели,
   PostgreSQL row-lock concurrency, реальный AMQP/bootstrap или доступ из другой LAN-машины.

7. **Срок хранения.** API немедленно запрещает доступ после TTL; физический reaper
   идемпотентно удаляет файлы и payload. Для уже удалённого задания возвращается 404,
   для ещё существующего истёкшего — 410. Active jobs не выбираются reaper.
